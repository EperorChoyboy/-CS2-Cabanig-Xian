# Travel Fare Calculator

## Description 
This program calculates the travel fare cost a passenger needs to pay. 

## Version 1 - Original code without input validation 
- Input: Accepts a passenger's name, distance and the amount of passengers on board.
- Process: Calculates and displays the travel fare cost.
- Output: Travel fare cost.
- Does not include input validation. 

## Version 2 - latest code with input validation
- Input: Accepts a passenger's name, distance and the amount of passengers on board.
- Process: Calculates and displays the travel fare cost.
- Output: Travel fare cost.
- will check if the passenger's name is valid.
- will check if the distance is above 0.
- will check if the passenger amount is positive.
